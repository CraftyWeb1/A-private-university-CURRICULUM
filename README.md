# Dar al-Ilm

A personal university in the browser: ten schools, a seasonal timetable, a library, an author’s room, a Qur’an journal, and a curiosity list. Progress is saved locally; use Export notebook to keep a copy.

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually `http://localhost:5173`).

## On your phone or tablet

The live site is:

**https://craftyweb1.github.io/A-private-university-CURRICULUM/**

Open that link in Safari (iPhone) or Chrome (Android tablet / PC). Add it to the Home Screen if you want an icon.

Notes live in that device’s browser. To copy your planner from the PC to the phone: **Export notebook** on one, **Import notebook** on the other.
